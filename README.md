# SportSpot

**SportSpot** — Android-приложение на Kotlin для поиска, оценки и дополнения информации об общедоступных спортивных площадках.

## Задача проекта

Помочь пользователям находить площадки для баскетбола, футбола, волейбола и воркаута и оценивать условия занятий по координатам, характеристикам, фотографиям и отзывам сообщества.

## Как работает приложение

1. Пользователь открывает SportSpot и просматривает доступные спортивные площадки.
2. При желании можно найти площадки рядом с собой с помощью геолокации.
3. На главной можно выбрать вид спорта, найти нужную площадку и открыть её карточку или карту.
4. Ранее загруженные площадки сохраняются для просмотра без интернета.

## Предполагаемый функционал

Ниже описаны возможности, которые планируется получить к завершению проекта.

1. **Карта спортивных площадок**
   - Отображение спортивных площадок на карте.
   - Определение местоположения пользователя через GPS.
   - Поиск ближайших площадок в заданном радиусе.
   - Ручной выбор района при отсутствии доступа к геолокации.

2. **Поиск и фильтрация**
   - Поиск площадок по названию или местоположению.
   - Фильтрация по видам спорта: футбол, баскетбол, волейбол, теннис, воркаут.
   - Сортировка площадок по расстоянию и пользовательской оценке.
   - Фильтрация по дополнительным характеристикам.

3. **Карточка спортивной площадки**
   - Название, местоположение и вид спорта.
   - Информация о покрытии, освещении и оборудовании.
   - Фотографии, отзывы и оценки пользователей.
   - Возможность открыть маршрут до площадки.

4. **Регистрация и авторизация**
   - Создание учётной записи и вход в приложение.
   - Хранение пользовательских данных через Supabase Auth.
   - Возможность просмотра площадок без авторизации.

5. **Оценки и отзывы**
   - Оценка площадки по пятибалльной шкале.
   - Добавление текстового отзыва.
   - Прикрепление фотографий.
   - Редактирование и удаление собственных отзывов.

6. **Добавление новых площадок**
   - Создание карточки новой спортивной площадки.
   - Указание названия, вида спорта и характеристик.
   - Получение координат через GPS или выбор точки на карте.
   - Отправка площадки на модерацию перед публикацией.

7. **Избранные площадки**
   - Добавление и удаление площадок из избранного.
   - Просмотр сохранённых площадок.
   - Доступ к ранее загруженной информации без интернета.

8. **Личный профиль**
   - Просмотр информации о пользователе.
   - Просмотр собственных отзывов и предложенных площадок.
   - Редактирование данных профиля.

9. **Локальное хранение и офлайн-режим**
   - Кеширование информации о площадках через Room.
   - Просмотр ранее сохранённых данных без интернета.
   - Хранение настроек через DataStore.
   - Обработка ошибок подключения и повторная загрузка.

10. **Модерация пользовательских данных**
    - Проверка предложенных площадок.
    - Подтверждение или отклонение новых объектов.
    - Публикация только одобренных площадок.

## Архитектура проекта

SportSpot разрабатывается по принципам **Clean Architecture**. Код Android-приложения разделён на четыре части:

- **Domain** — основные модели и правила работы приложения.
- **Data** — получение данных из API, работа с базой данных и GPS.
- **Presentation** — экраны, элементы интерфейса и их логика.
- **App** — запуск приложения и объединение всех частей.

Такое разделение помогает поддерживать проект и добавлять новые возможности без переделки всего приложения.

## Технологии

- **Android:** Kotlin, Jetpack Compose, Material 3, Hilt, Coroutines/Flow.
- **Работа с данными:** Retrofit, OkHttp, Room, DataStore.
- **Внешние данные:** OpenStreetMap и Overpass API.
- **Серверная часть:** Supabase, PostgreSQL, Edge Functions.
- **Тестирование:** JUnit, Robolectric, Compose UI Test, MockWebServer, Deno-тесты и Postman/Newman.
- **Для будущих функций:** Supabase Auth, Storage и камера (CameraX).

## Источники данных

Основной источник информации о спортивных площадках — **OpenStreetMap**. Для поиска объектов используется **Overpass API**. Приложение получает эти данные через серверную функцию Supabase, а ранее загруженные сведения могут сохраняться в локальной базе Room.

Количество площадок и их характеристики зависят от полноты данных OpenStreetMap. При использовании внешних данных необходимо соблюдать правила соответствующих сервисов и указывать авторство [участников OpenStreetMap](https://www.openstreetmap.org/copyright).

Отзывы, оценки и фотографии, которые в будущем добавят пользователи SportSpot, будут относиться к самому приложению и не станут частью OpenStreetMap.
