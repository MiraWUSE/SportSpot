# SportSpot

**SportSpot** — Android-приложение на Kotlin для поиска, оценки и дополнения информации об общедоступных спортивных площадках.

## Задача проекта

Помочь пользователям находить площадки для баскетбола, футбола, волейбола и воркаута и оценивать условия занятий по координатам, характеристикам, фотографиям и отзывам сообщества.

## Основной сценарий

1. Пользователь открывает карту и разрешает GPS либо выбирает район вручную.
2. Приложение показывает площадки, полученные из OpenStreetMap через Overpass API.
3. Пользователь фильтрует список по виду спорта и просматривает карточку.
4. Пользователь может добавить площадку в избранное, оставить отзыв с фотографией или предложить новую площадку.

## Предполагаемый функционал

1. **Карта спортивных площадок**
   - Отображение спортивных площадок на интерактивной карте.
   - Определение местоположения пользователя через GPS.
   - Поиск ближайших площадок в заданном радиусе.
   - Ручной выбор района при отсутствии доступа к геолокации.

2. **Поиск и фильтрация**
   - Поиск площадок по названию или местоположению.
   - Фильтрация по видам спорта: футбол, баскетбол, волейбол, теннис, воркаут.
   - Сортировка площадок по расстоянию и пользовательской оценке.
   - Фильтрация по дополнительным характеристикам при наличии соответствующих данных.

3. **Карточка спортивной площадки**
   - Название и местоположение площадки.
   - Вид спорта и доступные характеристики.
   - Информация о покрытии, освещении и оборудовании.
   - Фотографии, отзывы и средняя оценка пользователей.
   - Возможность открыть маршрут до площадки во внешнем навигационном приложении.

4. **Регистрация и авторизация**
   - Создание учётной записи.
   - Вход в приложение.
   - Хранение пользовательских данных через Supabase Auth.
   - Возможность просмотра общедоступных площадок без авторизации.

5. **Оценки и отзывы**
   - Оценка площадки по пятибалльной шкале.
   - Добавление текстового отзыва.
   - Прикрепление фотографий через камеру смартфона.
   - Редактирование и удаление собственных отзывов.

6. **Добавление новых площадок**
   - Создание карточки новой спортивной площадки.
   - Указание названия, вида спорта и характеристик.
   - Автоматическое получение координат через GPS или выбор точки на карте.
   - Добавление фотографий через камеру.
   - Отправка новой площадки на модерацию перед публикацией.

7. **Избранные площадки**
   - Добавление площадок в избранное.
   - Просмотр сохранённых площадок.
   - Удаление площадок из избранного.
   - Сохранение ранее загруженной информации для просмотра без интернета.

8. **Личный профиль**
   - Просмотр информации о пользователе.
   - Просмотр собственных отзывов.
   - Просмотр предложенных спортивных площадок.
   - Редактирование данных профиля.

9. **Локальное хранение и офлайн-режим**
   - Кеширование информации о площадках через Room.
   - Просмотр ранее сохранённых данных без подключения к интернету.
   - Хранение пользовательских настроек через DataStore.
   - Обработка ошибок подключения с возможностью повторного запроса.

10. **Модерация пользовательских данных**
    - Проверка предложенных спортивных площадок.
    - Подтверждение или отклонение добавленных объектов.
    - Предотвращение публикации неподтверждённых площадок.

## Планируемые технологии

- **Android:** Kotlin, Jetpack Compose, Material 3, Clean Architecture, Hilt, Coroutines/Flow.
- **Внешние данные:** OpenStreetMap / Overpass API.
- **Облачная часть:** Supabase Auth, PostgreSQL, Storage и Edge Functions.
- **Локальное хранилище:** Room, DataStore.
- **Аппаратные возможности:** GPS, камера (CameraX).
- **Тестирование:** JUnit, MockK, Compose UI Test, Kover.
