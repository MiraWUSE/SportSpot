# Настоящая карта OSM

Большая карта и мини-карта главной используют один компонент `OsmMap`:
MapLibre Native Android **13.7.1**, артефакт
`org.maplibre.gl:android-sdk-opengl`, через Compose `AndroidView` / `TextureView`.
Выбран OpenGL-вариант без обязательного Vulkan. SDK требует API 23, приложение
сохраняет minSdk 24; APK содержит в том числе armeabi-v7a и arm64-v8a.
Новых разрешений нет: необязательное ACCESS_WIFI_STATE из SDK удалено при merge.

## Источник и лицензии

Локальный raster-стиль в `OsmMapTiles.kt` загружает стандартные тайлы
`https://tile.openstreetmap.org/{z}/{x}/{y}.png` (256 px, zoom до 19).
Удалённых demo-стилей, ключей, шрифтов, sprites и телеметрии нет.
На обеих картах есть отдельная кликабельная строка
«© OpenStreetMap contributors», ведущая на [copyright OSM](https://www.openstreetmap.org/copyright)
с информацией об ODbL. Футер отделён от кнопок мини-карты; большая карта
ограничивается доступной высотой, чтобы подпись помещалась и после поворота.

MapLibre распространяется по [BSD 2-Clause](https://github.com/maplibre/maplibre-native/blob/android-v13.7.1/LICENSE.md).
Исходный текст лицензии включён в APK:
`assets/licenses/maplibre-bsd-2-clause.txt`.

## HTTP и правила тайлов

Настройка соответствует [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/):

- HTTPS и стабильный User-Agent
  `SportSpot/1.0 (+https://github.com/MiraWUSE/SportSpot)`.
- Отдельный клиент OkHttp только для MapLibre: HTTP-кеш 64 MiB в cacheDir/osm-http,
  стандартная обработка Cache-Control/Expires и условных запросов ETag/Last-Modified.
  Заголовки no-cache не добавляются.
- `prefetchZoomDelta = 0` задан в options и нативной карте. Нет OfflineManager,
  скачивания областей, фоновых заданий и предварительной загрузки других zoom.
  Мини-карта создаётся при появлении в видимой области LazyColumn.
- SDK также использует свой обычный кеш ресурсов. Повторный просмотр уже
  закешированных тайлов возможен, гарантированного офлайн-покрытия нет.
- Запросы карты не содержат JWT/API-ключей SportSpot; URL запросов не логируются.

Сервис OSM работает без SLA. При росте нагрузки потребуется разрешённый
альтернативный провайдер; бесплатный публичный сервер нельзя использовать
для массовой загрузки или скачивания городов.

## Поведение и файлы

- `OsmMap.kt`: MapView и lifecycle, камера, GeoJSON/CircleLayer, обработка нажатий,
  атрибуция, сообщения о сети/загрузке, повторная попытка. Listeners, memory callback
  и network callback освобождаются при удалении компонента.
- `MapSelection.kt`: группировка только точных одинаковых координат,
  выбор по полному SpotId и решение, когда менять камеру.
- `MapScreen.kt`: прежние состояния данных, карточка выбранной площадки
  и переход в детали. `HomeComponents.kt`: мини-карта 158 dp, счётчик и кнопка.
- Маркеры используют настоящие Spot.location через проекцию SDK.
  Вне кадра они обрезаются естественно, к краю не прижимаются.
  Повторное нажатие на совпадающую точку циклически выбирает все её SpotId.
- Обзор большой карты: zoom 13.5, мини-карты: 12, вход из деталей: 15.5.
  Pan/zoom сохраняются в Parcelable CameraPosition через rememberSaveable.
  Новый центр поиска перемещает камеру; рекомпозиция и выбор маркера её не сбрасывают.
- Pan не запускает поиск. Domain/Data, GPS, радиус 1000 м и навигация не изменены.
  Мини-карта не обрабатывает жесты карты, позволяя прокручивать главную.
- Сбой тайлов не заменяет список площадок ошибкой API.
  Есть сообщение об отсутствии сети и повторная загрузка карты; ожидание
  незавершённой загрузки ограничено 20 секундами.
  Состояние сети обновляется из onCapabilitiesChanged/onLost; синхронное
  повторное чтение activeNetwork внутри callback не используется.
  Ошибки отдельных тайлов учитываются через OnTileActionListener, отдельно
  от загрузки стиля; завершённый кадр не скрывает ошибку тайлов.

OSM raster сохраняет исходные цвета в обеих темах. Маркеры, подписи и панели
используют текущую тему SportSpot. Полярные широты за пределами Web Mercator
(±85.05112878°) не рисуются; недопустимый центр показывает сообщение.

## Проверка

Из `android/`: `ktlintCheck`, `:domain:test`, `:data:testDebugUnitTest`,
`:presentation:testDebugUnitTest`, `:app:testDebugUnitTest`, `:app:assembleDebug`.
325 JVM-тестов проходят. Вместо пяти тестов удалённой Canvas-проекции добавлены
шесть проверок выбора/камеры; ещё три теста проверяют HTTP-кеш/UA/304/503
через MockWebServer без внешней сети.

На Pixel 9 Pro, API 37, x86_64 (16 KiB pages) проходят 14 инструментальных
тестов: Presentation 11, App 2, Data 1. Три новых теста используют настоящий
нативный рендерер без внешней сети: сохранение камеры,
background/foreground, смена центра и выбор совпадающих площадок.
Отдельно через публичный ModuleProvider подставляется ответ 503:
проверяются сообщение об ошибке тайлов и повторная попытка; провайдер
восстанавливается после теста. Этот сценарий также не обращается во внешнюю сеть.
Живые тайлы проверяются отдельно вручную, а не являются условием тестов.
На эмуляторе показаны 21 площадка Нижнего Новгорода и, после выдачи GPS-прав
и задания координат Лужников, 56 площадок Москвы. Проверены обе темы,
переход из деталей, поворот, прокрутка главной, отключение/возврат сети
и запуск с ранее заполненным кешем без сети.

На физическом Redmi 9 нужно дополнительно проверить установку, плавность жестов
и GPS. Его отсутствие при проверке не заменяется утверждением об успешном запуске.
